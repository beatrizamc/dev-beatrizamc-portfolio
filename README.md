# Portfólio Profissional 

Bem-vindo(a) ao repositório do meu portfólio pessoal. Este projeto apresenta minha trajetória acadêmica e profissional em Ciência da Computação e Engenharia de Software, reunindo meus principais projetos, competências técnicas e formas de contato.

**Live Demo:** [https://beatrizamc.github.io](https://beatrizamc.github.io)

---

### Key Features:
- **Tema Dinâmico (Dark/Light Mode):** Alternância de cores com persistência de preferência via `localStorage`.
- **Formulário de Contato Integrado:** Envio direto de mensagens utilizando a API do Formspree com validação dinâmica de campos.
- **Grid de Projetos:** Exibição resumida dos repositórios de destaque (UX/UI, Python Web, Java POO).
- **Design Responsivo:** Adaptado para navegação em dispositivos móveis e desktops.

---

## Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3 (Variáveis CSS, Flexbox, CSS Grid), JavaScript (ES6+)
- **Tipografia:** Plus Jakarta Sans (Google Fonts)
- **Integrações:** Formspree API (Formulário de Contato)
- **Hospedagem:** GitHub Pages
